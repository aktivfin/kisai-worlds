БЫСТРЫЙ ЗАПУСК

Установка KisAI Worlds

Windows

  1. Установи Node.js 20+.
  2. Запусти INSTALL_WINDOWS.ps1.
  3. Установщик создаст локальный config и ярлык на рабочем столе.
  4. Для LAN используй START_LAN_WINDOWS.bat.
powershell -ExecutionPolicy Bypass -File .\INSTALL_WINDOWS.ps1

Linux

  1. Установи Node.js 20+.
  2. Запусти ./INSTALL_LINUX.sh.
  3. Установщик добавит launcher в ~/.local/bin без root.
  4. Для LAN используй ./START_LAN_LINUX.sh.
chmod +x INSTALL_LINUX.sh && ./INSTALL_LINUX.sh

API-ключи хранятся только в локальном data/config.json и не должны попадать в Git.
